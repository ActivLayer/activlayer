# Roadmap

The roadmap is directional and will be refined through GitHub Discussions.

## Near term

- Async and parallel branch execution
- Cancellation and explicit rejection decisions
- JSON Schema publication and Studio conformance fixtures
- Structured event subscribers and OpenTelemetry integration
- Pluggable durable stores
- Interactive terminal graph editing

## Later

- Distributed execution and leases
- Scheduled and event-driven triggers
- Sandboxed tool adapters
- Signed extension packages and compatibility metadata
- Cross-language specification conformance tests

Open a discussion to propose a use case before starting a large implementation.
